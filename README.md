Turn your Android phone into a wireless mouse and touchpad for your PC.

#📥 Download
Windows server: mouse_server.exe
Android app: MouseRemote.apk (arm64)
#🚀 Setup
Run mouse_server.exe on your PC. Allow it through Windows Firewall.
Install MouseRemote.apk on your phone.
Make sure both devices are on the same Wi-Fi.
Open the app → tap ⚙️ → tap your PC's name. Done.
#✨ Features
Touchpad cursor control
Left/right click, drag-and-drop
Scrolling
Automatic PC discovery over Wi-Fi
#⚠️ Requirements
Windows 10/11 (64-bit)
Android 8.0+ (arm64)
